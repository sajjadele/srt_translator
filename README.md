# Academic SRT Subtitle Translator (مترجم هوشمند زیرنویس دانشگاهی)

سیستم ترجمه‌ی تخصصی و دانشگاهی فایل‌های زیرنویس انگلیسی (`.srt`) به زبان فارسی با حفظ ۱۰۰٪ همگامی زمان‌بندی (Sync) و اصطلاحات استاندارد علمی، مبتنی بر معماری پروژه «ترجمان».

## قابلیت‌های کلیدی

1. **حفظ کامل زمان‌بندی و صفر درصد ناهماهنگی (Zero Timing Drift):**
   - هوش مصنوعی صرفاً متن بلاک‌ها را ترجمه می‌کند؛ استخراج، نگهداری و بازسازی تایم‌کدها در لایه‌ی پایتون مدیریت شده و تغییرناپذیرند.
2. **پیشگیری از شکستگی جملات (Anti-Fragmentation):**
   - به دلیل قرار گرفتن فعل در انتهای جمله در زبان فارسی (ساختار SOV)، جملاتی که در چند بلاک متوالی زیرنویس بریده شده‌اند، از طریق **پنجره‌ی لغزان کانتکست (Sliding Window)** به صورت یکپارچه برای مدل ارسال می‌شوند.
3. **قرارداد اصطلاحات فنی (Smart-Persian Terminology):**
   - حفظ اصطلاحات و کلمات تخصصی لاتین یا آوردن معادل مصوب دانشگاهی با درج عبارت انگلیسی درون پرانتز در اولین اشاره.
   - واژه‌نامه‌ی پیش‌فرض با بیش از ۱٬۰۰۰ اصطلاح هوش مصنوعی و علوم پایه (`data/dict/en_fa_academic.json`).
4. **رابط کاربری دوگانه:**
   - **ربات تلگرام (`aiogram 3.x`):** دریافت فایل زیرنویس، امکان تعیین زمینه درسی، نمایش نوار پیشرفت لحظه‌ای (Progress Bar)، و ارسال فایل ترجمه‌شده.
   - **خط فرمان (CLI):** قابلیت ترجمه محلی و دسته‌ای فایل‌ها بدون وابستگی به اینترنت تلگرام.
5. **زنجیره Fallback و تاب‌آوری:**
   - پشتیبانی از روترهای سازگار با OpenAI (مثل Bynara، OpenRouter، Groq، Gemini، OpenAI).
   - انتقال خودکار به مدل پشتیبان در صورت خطای Rate Limit یا قطعی شبکه.

## راه‌اندازی و نصب

```bash
# ۱. فعال‌سازی محیط مجازی
python3 -m venv .venv
source .venv/bin/activate

# ۲. نصب وابستگی‌ها
pip install -r requirements.txt

# ۳. تنظیم فایل متغیرهای محیطی
cp .env.example .env
```

فایل `.env` را باز کرده و کلیدهای مورد نظر را تنظیم کنید:

```env
# روتر یا ارائه‌دهنده هوش مصنوعی
LLM_BASE_URL=https://router.bynara.id/v1
LLM_API_KEY=your_api_key_here
LLM_MODELS=agnes-2.5-flash,minimax-m3,mistral-medium-3-5

# توکن ربات تلگرام (از @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

## استفاده از ابزار

### ۱. استفاده از طریق خط فرمان (CLI)

```bash
# ترجمه یک فایل زیرنویس
python -m app.cli input_lecture.srt -o output_fa.srt --topic "Deep Learning"

# پارامترهای اختیاری:
# --output / -o : مسیر فایل خروجی (پیش‌فرض: [نام]_fa.srt)
# --topic       : موضوع درس (پیش‌فرض: General Academic)
# --batch-size  : اندازه دسته‌ها (پیش‌فرض: 15)
```

### ۲. اجرای ربات تلگرام

```bash
python -m app.bot.main
```

1. در تلگرام وارد ربات شوید و دستور `/start` را بزنید.
2. با دکمه‌های شیشه‌ای یا دستور `/topic [نام درس]` موضوع را انتخاب کنید.
3. فایل `.srt` را ارسال کنید و خروجی فارسی را با نوار وضعیت لحظه‌ای دریافت کنید.

## ساختار پروژه

```text
srt_translator/
├── app/
│   ├── config.py                 # تنظیمات و اعتبارسنجی محیطی
│   ├── core/
│   │   ├── models.py             # کلاس‌های SubtitleCue، SubtitleDocument و Batch
│   │   ├── srt_parser.py         # پارسر و سریال‌ساز مقاوم SRT
│   │   ├── batcher.py            # پنجره لغزان و دسته‌بندی کانتکست
│   │   ├── engine.py             # موتور ارتباط با LLM و زنجیره Fallback
│   │   └── glossary.py           # مدیریت واژه‌نامه و اصطلاحات
│   ├── bot/
│   │   ├── main.py               # راه‌انداز ربات تلگرام
│   │   ├── handlers.py           # هندلرهای پیام و آپلود فایل
│   │   └── keyboards.py          # کیبوردهای انتخاب موضوع
│   └── cli.py                    # رابط خط فرمانی (CLI)
├── data/
│   └── dict/
│       └── en_fa_academic.json   # واژه‌نامه تخصصی اصطلاحات دانشگاهی
├── tests/                        # تست‌های خودکار واحد و یکپارچه‌سازی (pytest)
└── specs/                        # مستندات و قراردادهای معماری بر اساس Spec-Kit
```
